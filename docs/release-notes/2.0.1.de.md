# Dub Police 2.0.1 – Fehlerbehebungen

<p align="center"><a href="2.0.1.md">English</a> · <b>Deutsch</b> · <a href="2.0.1.fr.md">Français</a></p>

Ein kleines Update, das zwei Probleme aus dem Feedback behebt. Alles Neue aus 2.0 steht in den [Release Notes zu 2.0.0](2.0.0.de.md).

## Behoben

- **Das Fenster öffnete sich nicht, wenn die ZIP mit Windows entpackt wurde.** Windows markiert alle Dateien aus einer heruntergeladenen ZIP, und .NET lädt dann `Python.Runtime.dll` nicht. Die Fehlermeldung nannte fälschlich eine fehlende WebView2-Runtime als Grund. Dub Police entfernt die Markierung jetzt beim Start von seinen eigenen Dateien. Öffnet sich das Fenster trotzdem nicht, nennt die Meldung jetzt auch diese Ursache: Rechtsklick auf `DubPolice.zip`, **Eigenschaften**, **Zulassen** anhaken, dann neu entpacken.
- **Season 2: Eine installierte alte Version wurde nicht gefunden.** Dub Police suchte die englischen Stimmen nur in einem Ordner namens `English`, wie auf der Disc. Ein installiertes Spiel hat sie direkt in `Pack` und die synchronisierten Stimmen in einem Unterordner wie `localized\german`. Jetzt klappt beides. Die Disc funktioniert wie bisher.

## Aktualisieren

`DubPolice.zip` von der [Release-Seite](https://github.com/MrLuigi938/DubPolice/releases/latest) laden, entpacken und `DubPolice.exe` starten. Mit 2.0.0 installierte Episoden bleiben, wie sie sind, und müssen nicht neu installiert werden.

An SFFan11 fürs Melden beider Probleme.
