# Dub Police 2.0.1 – Bug fixes

<p align="center"><b>English</b> · <a href="2.0.1.de.md">Deutsch</a> · <a href="2.0.1.fr.md">Français</a></p>

A small update that fixes two problems from the feedback. Everything new in 2.0 is described in the [release notes for 2.0.0](2.0.0.md).

## Fixed

- **The window did not open after unpacking the ZIP with Windows.** Windows marks every file unpacked from a downloaded ZIP, and .NET then refuses to load `Python.Runtime.dll`. The error message wrongly blamed a missing WebView2 runtime. Dub Police now removes the mark from its own files when it starts. Should the window still not open, the message now names this cause too: right-click `DubPolice.zip`, **Properties**, tick **Unblock**, then unpack it again.
- **Season 2: an installed old version was not found.** Dub Police looked for the English voices only in a folder named `English`, as on the disc. An installed game keeps them directly in `Pack`, with the dubbed voices in a subfolder such as `localized\german`. Both layouts now work. The disc keeps working as before.

## Updating

Download `DubPolice.zip` from the [releases page](https://github.com/MrLuigi938/DubPolice/releases/latest), unpack it and start `DubPolice.exe`. Episodes installed with 2.0.0 stay as they are; there is no need to install them again.
