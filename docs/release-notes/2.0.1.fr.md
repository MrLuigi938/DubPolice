# Dub Police 2.0.1 – Corrections

<p align="center"><a href="2.0.1.md">English</a> · <a href="2.0.1.de.md">Deutsch</a> · <b>Français</b></p>

Une petite mise à jour qui corrige deux problèmes signalés. Toutes les nouveautés de la 2.0 sont décrites dans les [notes de version 2.0.0](2.0.0.fr.md).

## Corrigé

- **La fenêtre ne s'ouvrait pas après avoir décompressé le ZIP avec Windows.** Windows marque chaque fichier issu d'un ZIP téléchargé, et .NET refuse alors de charger `Python.Runtime.dll`. Le message d'erreur accusait à tort un runtime WebView2 manquant. Dub Police retire désormais cette marque de ses propres fichiers au démarrage. Si la fenêtre ne s'ouvre toujours pas, le message cite maintenant aussi cette cause : clic droit sur `DubPolice.zip`, **Propriétés**, cochez **Débloquer**, puis décompressez-le à nouveau.
- **Saison 2 : une ancienne version installée n'était pas trouvée.** Dub Police ne cherchait les voix anglaises que dans un dossier nommé `English`, comme sur le disque. Un jeu installé les garde directement dans `Pack`, avec les voix doublées dans un sous-dossier comme `localized\french`. Les deux organisations fonctionnent désormais. Le disque fonctionne comme avant.

## Mettre à jour

Téléchargez `DubPolice.zip` depuis la [page des versions](https://github.com/MrLuigi938/DubPolice/releases/latest), décompressez-le et lancez `DubPolice.exe`. Les épisodes installés avec la 2.0.0 restent tels quels, inutile de les réinstaller.
